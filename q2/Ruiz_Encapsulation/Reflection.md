## Reflection Activity 1

How does using @property make your code easier to read compared to using
traditional get_ and set_ methods?

Using @property makes my code easier to read because it allows me to access a method like a normal variable without using parentheses. For example, instead of using a1.get_balance() to get the balance, I can simply write a1.balance. It also allows me to keep the data private while still making it easier to access. This makes my code cleaner, simpler, and easier to understand compared to using traditional getter and setter methods.
