## Reflection Activity 1

How does using @property make your code easier to read compared to using
traditional get_ and set_ methods?

Using the @property decorator makes code significantly easier to read because it allows methods to be accessed as if they were regular attributes without needing parentheses. Rather than relying on traditional, verbose getter and setter method calls, developers can use an intuitive dot notation that makes code look and feel like standard variable access. This removes the visual clutter of redundant method syntax, resulting in a cleaner, more concise, and much easier-to-follow codebase.
